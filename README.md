# Asmi Mishra — Personal Portfolio Website

An elegant, modern, and aesthetically refined personal portfolio crafted for **Asmi Mishra**, a first-year B.Tech student majoring in **Computer Science and Artificial Intelligence** at **Newton School of Technology, Rishihood University** (Sonipat, Haryana).

> *"Curiosity drives me. Code empowers me. Innovation inspires me."*

## 💻 How to View & Run Locally

### Option 1: Direct File Opening
Double-click `index.html` on your computer or right-click and open with **Google Chrome**, **Safari**, or **Firefox**.

### Option 2: Local Python Server
Open terminal in this directory and run:
```bash
python3 -m http.server 8000
```
Then navigate to `http://localhost:8000` in your browser.

---

## 🌐 Deploying to the Web

- **GitHub Pages**: Push this directory to a GitHub repository, go to **Settings > Pages**, choose the `main` branch, and save.
- **Vercel / Netlify**: Drag-and-drop the portfolio folder directly into the Netlify or Vercel dashboard for an instant live URL.
